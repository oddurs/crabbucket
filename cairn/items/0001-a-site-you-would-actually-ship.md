The smallest set of work that makes crabbucket usable for a real repository site.

Two threads run through it. The first is that the gates are the product, and
untested gates are a claim rather than a guarantee — so the integration suite
is the highest-priority item here, above any feature. The second is that a
documentation framework whose code blocks are grey and whose headings cannot
be linked to is not finished, however correct it is underneath.

`crab new` is what turns all of it into something someone else can start.
