The first milestone makes crabbucket correct; this one makes it pleasant.

Everything here is about the reading experience of a documentation site: a
way to jump around a long page, a way to find a page you half-remember, and
the component syntax that lets a Markdown page reach a designed component
without leaving Markdown.

Nothing in this milestone is allowed to break the zero-JavaScript default.
Each piece that needs script ships it only when the site opts in, and each
degrades to something usable without it.
