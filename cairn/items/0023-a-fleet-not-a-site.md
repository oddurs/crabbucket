Prove the theme seam by implementing it twice, and give components the guarantee content already has.

One site does not need a design system. Twelve repositories that should look
like they belong to the same person do — and that is the real argument for
first-class design systems on small sites.

So this milestone is about the second site: a second theme to find out what
`Theme` got wrong, a generated `Route` enum so a component's links fail at
compile time rather than at build time, and the metadata that makes a page
worth sharing.
